# Projekt-G.01. - Gate Dominion

AI Game Development Studio oparte na Godot Engine 4.2.

## Szybki start

```bash
Start.bat
```

Skrypt automatycznie:
1. Sprawdza instalacje Pythona
2. Pobiera Godot Engine (jesli brak)
3. Generuje projekt, kod, assety, sceny i dane
4. Buduje i uruchamia gre

## Struktura

```
Start.bat           - Glowny skrypt budowania i uruchamiania
tools/              - Generatory projektu (Python)
```

## Powiazane repozytoria

- **ML-AI** - Projekty AI/ML (NeuroForge Local AI Studio, analiza RX 9070 XT)
